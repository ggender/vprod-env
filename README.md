# vprod-env

Опциональная среда курса: проекты и Claude Code на сервере, VS Code ученика подключается к нему через Remote-SSH.

- [`requirements.md`](requirements.md) — требования к установщику: сводка для проверки и детали для агента
- [`build-plan.md`](build-plan.md) — план сборки и тестов: промпты, модели, задачи на потом
- [`setup.sh`](setup.sh), [`setup.ps1`](setup.ps1) — установщик на компьютере ученика: macOS и Linux, Windows
- [`preflight.sh`](preflight.sh), [`server.sh`](server.sh) — части установщика, которые работают на сервере
- [`LICENSE`](LICENSE) — MIT

## Второй компьютер

Сервер пускает только по ключам, которые на нём записаны. Чтобы работать с сервером со второго компьютера, добавьте на сервер ключ этого компьютера. Приватный ключ между компьютерами не копируйте.

1. На втором компьютере запустите ту же команду установки, что и на первом, с теми же ответами (пользователь, имя подключения). Установщик создаст ключ и остановится с сообщением `This server is already set up with another key`. Так и должно быть.
2. На втором компьютере покажите публичный ключ. Его можно пересылать: это не секрет.
   - macOS и Linux: `cat ~/.ssh/vprod_ed25519.pub`
   - Windows (PowerShell): `Get-Content $env:USERPROFILE\.ssh\vprod_ed25519.pub`
3. На первом компьютере добавьте этот ключ на сервер, вставив строку ключа вместо `<ключ>`:
   ```
   echo '<ключ>' | ssh vprod 'cat >> ~/.ssh/authorized_keys'
   ```
4. На втором компьютере запустите команду установки ещё раз. Она войдёт по новому ключу, скажет `Everything is already set up.`, настроит подключение `vprod` и VS Code.

Если имя подключения не `vprod`, в путях выше замените `vprod` на него. Чтобы отключить компьютер, удалите строку его ключа из `~/.ssh/authorized_keys` на сервере.

## Если что-то пошло не так

- **Красная плашка «noVNC encountered an error»**, в тексте ошибки есть `chrome-extension://`. Ошибку выдаёт расширение браузера, а не сервер: noVNC показывает любую ошибку на странице. Не закрывайте терминал с установщиком и откройте ту же ссылку `http://127.0.0.1:…/vnc.html…` в Safari или в окне инкогнито Chrome, где расширения выключены.
