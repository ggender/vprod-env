# AGENTS.md - vprod-env

Установщик удалённой среды курса [«Вайбкодинг»](https://vibecoding.main.guide/): Claude Code работает на сервере Ubuntu, а не на компьютере пользователя, VS Code на компьютере подключается к серверу через Remote-SSH.

У репозитория два режима:

1. **Установка среды** - режим по умолчанию. Пользователь хочет получить настроенный сервер и VS Code, подключённый к нему. Правила - в этом файле.
2. **Разработка установщика** - пользователь меняет или проверяет сами скрипты (`setup.sh`, `setup.ps1`, `preflight.sh`, `server.sh`, `github.sh`), требования или план проверки. Только в этом режиме: до любых правок прочитать [`specs/README.md`](specs/README.md) целиком и работать по нему.

Если по просьбе непонятно, какой режим, - считать, что установка, и файлы репозитория не менять.

## Установка среды

Всё, что нужно пользователю, - в [README.md](README.md): требования к серверу, команды установки, что будет происходить, действия `desktop`, `login`, `check`, GitHub на сервере, второй компьютер, частые ошибки. Если README не хватает, чтобы объяснить поведение установщика, подробности - в `specs/requirements.md`.

### Как помогать

- Установщик запускается командой из README: она берёт релизную версию. Скрипты из этого клона не запускать и не править
- Команду запускает сам пользователь, в обычном окне терминала: на macOS и Linux - Терминал, на Windows - Windows PowerShell (PowerShell 7 пока не поддерживается). Установщик задаёт вопросы и один раз просит пароль root, ему нужен настоящий терминал
- Помочь собрать команду можно: ответы задаются заранее переменными `VPROD_HOST`, `VPROD_SSH_PORT`, `VPROD_USER`, `VPROD_SSH_ALIAS`, на Windows - параметрами `-ServerHost`, `-SshPort`, `-User`, `-Alias`
- Сообщения установщика - на английском. Объяснять их пользователю на его языке. Каждая ошибка говорит, что сделать: обычно запустить ту же команду ещё раз или действие `check`
- Чтобы разобрать проблему, просить вывод установщика целиком: по нему видно, на каком шаге он остановился

### Что делает только пользователь

- Вводит пароль root - в окне установщика. Не просить пароль, не принимать его в чате, не подставлять в команды, переменные и файлы. Если пароль всё же попал в чат, посоветовать сменить его в панели провайдера и только потом запускать установку
- Входит в Claude - на рабочем столе сервера, в Firefox сервера. Не открывать ссылку входа в своём браузере
- Вводит код GitHub на https://github.com/login/device, когда запускает `github.sh`

### Чего не делать

- Не менять сервер руками в обход установщика (SSH, файрвол, fail2ban, пользователь): можно потерять вход. Чинить - повторным запуском той же команды или по подсказке `check`
- Смотреть на сервер через `ssh <имя подключения>` можно. Что-то менять там - только с согласия пользователя
- Не править блок между `# BEGIN vprod-env <имя>` и `# END vprod-env <имя>` в `~/.ssh/config`: его пишет установщик
- Не копировать приватный ключ `~/.ssh/<имя подключения>_ed25519` на другие компьютеры. Второй компьютер подключается своим ключом, по README

### Чего установщик не умеет

Список - в README, раздел «Чего установщик не умеет». Сказать об этом прямо и не искать обходных путей.
